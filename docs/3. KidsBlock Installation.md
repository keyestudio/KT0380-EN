### 4.2 KidsBlock Programming

KidsBlock offers two programming methods; you can choose according to your preference:

- **Method 1: Online programming** (no installation required, works directly in a browser, supports saving projects to the local computer)
- **Method 2: Install the desktop software** (suitable for offline environments or users who prefer desktop software)

The operation interfaces and usage methods of the two methods are exactly the same. The entry processes are introduced separately below.

#### 4.2.1 Method 1: Online Programming

No download or installation is needed; just access it through a browser to start programming.

**Entering Online Programming**

1. Open [https://www.kidsblock.cc/ide](https://www.kidsblock.cc/ide) in a browser.

![](media/image-20260923100110771.png)

![wb](media/wb.png)

2. Click the "**Start Online Programming Now**" button on the page to enter the KidsBlock online programming interface.

![](media/image-20260923100330987.png)

![Img](./media/wb1.png)



#### 4.2.2 Method 2: Installing the Desktop Software

Suitable for users who need offline use or prefer desktop software.

##### Windows System Installation

**KidsBlock IDE Download**

**For Windows**

[Windows System](https://wiki.kidsbits.cc/projects/KidsBlock/en/latest/download/)

**KidsBlock IDE Installation**

1. Double-click the downloaded software "**KidsBlock.exe**".

![](media/kidsblock-1-179021161189215.png)

2\. Tick “**Anyone who uses this computer (all users)**”  and “**Next**”.

![](media/kidsblock-2-17902113555981.png)

3\. Click “**Browse...**” to choose an installation position and “**Install**”. Here I choose Disk C. You may save it in a convenient position.

![](media/kidsblock-3-17902113555982.png)

![](media/kidsblock-4-17902113555983.png)

4\. Wait for a while and “**Finish**”.

![](media/kidsblock-5-17902113555986.png)

5\. And you can see:

![](media/kidsblock-6-17902113555985.png)

**For MacOS**

1\. Enter the website to download KidsBlock software:

[MacOs System](https://wiki.kidsbits.cc/projects/KidsBlock/en/latest/download/)

2\. Click the installed “**KidsBlock.dmg**”.

![](media/kidsblock-11-17902113555984.png)

3\. And you will see:

![](media/kidsblock-12-17902113555987.png)

4\. Drag “**KidsBlock**” into **Applications** file.

![](media/kidsblock-13-179021135559811.png)

5\. There will be a “**Safety Prompt**” during copying.

![](media/kidsblock-14-17902113555988.png)

6\. Click “**Settings**” –> “**Privacy and Security**” to “**open anyway**”. And then “ **Open “KidsBlock”**”.

![](media/kidsblock-16-17902113555989.png)

![](media/kidsblock-17-179021135559810.png)

7\. A “**Privacy and Security**” box pops up, and then enter “**user name**” and “**password**”, and “**OK**”.

![](media/kidsblock-18-179021135559813.png)

8\. If prompted to update, please click on the update button to obtain the latest version of KidsBlock.

![](media/kidsblock-20-179021135559812.png)

9\. After a while, you can open the Kidsblock IDE page.

![kidsblock-19](media/kidsblock-19-179021135559814.png)

### 4.3 How to Use the KidsBlock Software

⚠️ **Special reminder:** The following takes the Windows system as an example; MacOS users can refer to it. Whether you enter through online programming or the desktop software, the operation methods are exactly the same.

#### 4.3.1 Selecting the Device

⚠️ **Special note:** The device used in this kit is the AI Chat Bot. For how to import the AI Chat Bot device, please refer to the content below. If you import other devices (or development boards), the method is similar and can be used as a reference.

1. Make sure the ESP32 main control board is successfully connected to the computer, then double-click the "**KidsBlock**" icon ![Img](./media/KidsBlock.png) to open the KidsBlock software (online programming users go directly to the IDE interface).

![1](media/1.png)

2. Click ![Img](./media/Equip.png), as shown below:

![Img](./media/Equip-1.png)

3. Since this tutorial uses the AI Chat Bot device, click to select the "**AI Chat Bot**" device, as shown below:

![Img](./media/Equip-3.png)

4. Connect the serial port (COM), click "**Connect**", as shown below:![](media/image-20260924091002971.png)

![Img](./media/Equip-4.png)

5. Then click "**Return to Editor**" to return to the code editing area, as shown below:

![Img](./media/Equip-5.png)

![Img](./media/Equip-6.png)

#### 4.3.4 Writing Code and Uploading

(**For the code upload steps in the following tutorials, please refer to this section.**)

**Method ①:** Write code by directly dragging code blocks into the code editing area, as shown below:

![Img](./media/Equip-9.png)

![Img](./media/Equip-11.png)
