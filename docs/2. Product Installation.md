#### Step 5

Required parts

![image33](media/image33-179055594263822.jpeg)

Note: Initialize the servo angle before installing the servo.

Connect the servo to the corresponding pins on the main board:

| Servo Wire | Definition | Main Board Pin |
| :---------: | :--------: | :------------: |
|    Brown   |    GND     |      GND       |
|     Red     |    VCC     |       5V       |
|    Orange  |    SIG     |      IO14      |

![](media/image-20260927093140013.png)

Upload the corresponding program to initialize the angle.

![](media/image-20260927093932263.png)

Then continue with the installation.
